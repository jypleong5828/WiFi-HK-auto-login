# WiFi.HK Auto Login

A Tampermonkey userscript that automatically clicks the WiFi.HK "Accept" button on the landing page, so you do not need to manually click it every time you connect to the network.

這是一個 Tampermonkey 使用者腳本，會在你連接到 WiFi.HK 時，自動點擊登入頁面的 "Accept" 按鈕，讓你不需要每次手動點擊同意。

## Features / 功能

- Automatically detects the WiFi.HK login page
- Clicks the "Accept" button automatically
- Removes the manual confirmation step
- Works with Tampermonkey in supported browsers

- 自動偵測 WiFi.HK 登入頁面
- 自動點擊 "Accept" 按鈕
- 移除手動確認步驟
- 可在支援 Tampermonkey 的瀏覽器中使用

## Installation / 安裝方式

1. Install Tampermonkey
2. Create a new userscript
3. Paste the script code
4. Save it
5. Connect to WiFi.HK

1. 安裝 Tampermonkey
2. 建立新的使用者腳本
3. 貼上腳本程式碼
4. 儲存
5. 連接到 WiFi.HK

## Usage / 使用方式

Connect to the WiFi.HK network and the script will automatically click the confirmation button when the page appears.

連接到 WiFi.HK 網路後，當頁面出現時腳本會自動點擊確認按鈕。

## Notes / 注意事項

- This script depends on the current WiFi.HK page structure.
- If the page changes, the selector may need updating.
- Use only on networks you are authorized to access.

- 此腳本依賴目前 WiFi.HK 頁面的結構。
- 若頁面更新，可能需要調整選擇器。
- 只能在你有權使用的網路環境中使用。
